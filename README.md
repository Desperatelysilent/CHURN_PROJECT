# Customer Churn Prediction & Retention Engine

An end-to-end Machine Learning solution designed to predict customer churn risk, identify underlying risk drivers using explainable AI (SHAP), and trigger personalized retention strategies via an interactive Streamlit dashboard.

## Business Problem
Customer acquisition costs significantly outweigh retention costs. This project helps businesses proactively identify high-risk customers before they cancel their subscriptions, enabling targeted marketing and support interventions.


## Key Features
* **Machine Learning Pipeline:** Data preprocessing, feature engineering, and model training.
* **Explainable AI (SHAP):** Local feature importance breakdowns to show *why* an individual customer is flagged.
* **Interactive Dashboard:** Built with Streamlit to allow real-time customer parameter input and immediate risk scoring.


## Tech Stack
* **Language:** Python
* **Data Processing & ML:** Pandas, NumPy, Scikit-learn, XGBoost, Joblib
* **Explainable AI:** SHAP
* **Web Framework:** Streamlit
